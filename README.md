# Reaidy_Business_Analyst

📊 Employee Attrition Data Cleaning and Dashboard
📌 Project Overview

This project focuses on cleaning and analyzing HR employee data to understand employee attrition patterns across departments and tenure.
Using Excel for data preprocessing and Power BI for data modeling and visualization, the project delivers an interactive dashboard that helps HR and management make data-driven workforce decisions.

🎯 Objectives

Clean and standardize HR employee datasets

Handle missing values, outliers, and inconsistent codes

Build a relational data model in Power BI

Analyze employee attrition trends by:

Department

Tenure

Job role (if applicable)

Create clear, interactive Power BI dashboards

🛠 Technologies Used

Microsoft Excel – Data cleaning and preprocessing

Power BI Desktop – Data modeling, relationships, and visualization
